Buka editor Scratch ↗

Cara membuka

  1. Klik tombol unduh di atas.
  2. Buka scratch.mit.edu/create.
  3. Pilih File → Load from your computer, lalu pilih file TangkapApel.sb3.
  4. Klik bendera hijau untuk mulai.

Cara main

  • Gerak: panah kiri/kanan atau tombol A/D.
  • Tangkap apel untuk menambah skor.
  • Apel yang lolos mengurangi nyawa (3 hati).
  • Makin lama, apel dan keranjang makin cepat.
  • Nyawa habis: muncul "Game Over" dan skor akhir.
